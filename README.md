# Salil Srivastav — Portfolio

A standalone, responsive portfolio site built with HTML, CSS, and JavaScript. It uses an editorial layout with custom project visuals, project stories, GRIDEE experience, skills, leadership, and a linked credentials section.

Open `index.html` in a browser to view the site. The resume download is included as `Salil-Srivastav-Resume.pdf`.

Certificate files are stored in `certificates/` and linked from the credentials section. The Red Hat document is labeled as course attendance, and the Adobe document as hackathon participation.

Project links are included for the Distributed Job Scheduler, Multi-Agent Competitive Intelligence, and RetinaGrade repositories. AgroTrack links to the GitHub profile until its direct repository URL is available.

SA-EffNetB3 is a five-class diabetic-retinopathy grading model built on an ImageNet-pretrained EfficientNetB3 backbone with a custom spatial-attention block. RetinaGrade is the Streamlit inference demo: it shows the model grade output and score distribution for a fundus image. This is a research and education project, not a diagnostic tool; the hosted demo processes uploads on its server.

- Live demo: https://retinagrade-sa-effnetb3.streamlit.app/
- Model and inference repository: https://github.com/salilsrii/retinagrade-app
